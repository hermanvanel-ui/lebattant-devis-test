Version A · Wizard

Étape par étape

Le client est guidé pas à pas dans un parcours en 6 écrans. Chaque étape pose 1 ou 2 questions max. Progress bar en haut. Ne peut pas passer à la suite tant que l'étape précédente n'est pas remplie.

Votre note
★★ ★★★

✓ Avantages

  • Très clair, impossible de se perdre
  • Idéal pour clients qui ne savent pas par où commencer
  • Validation à chaque étape = données propres
  • Très lisible sur mobile (peu d'info par écran)

✗ Inconvénients

  • Plus long à remplir (6 écrans)
  • Pas de vue d'ensemble du formulaire
  • Frustrant pour pros qui savent déjà ce qu'ils veulent
  • Plus de code pour gérer la navigation

★ Commentaire sur la Version A ★
Version B · One-pager

Tout sur une page

Toutes les sections déroulées sur une seule longue page. Le client scrolle, voit l'ensemble, peut sauter directement à ce qui l'intéresse. Aucune navigation, aucune validation par étape — juste un envoi en bas.

Votre note
★★ ★★★

✓ Avantages

  • Vue d'ensemble immédiate du formulaire
  • Idéal pour pros qui savent déjà ce qu'ils veulent
  • Plus rapide à remplir pour quelqu'un qui scrolle vite
  • Simple à coder, simple à maintenir

✗ Inconvénients

  • Peut paraître long et décourageant au premier abord
  • Plus dur à remplir sur mobile (gros scroll)
  • Risque de champs oubliés (pas de validation par étape)
  • Moins guidé pour les clients hésitants

★ Commentaire sur la Version B ★
Version C · Hybride

Sections pliables

Compromis entre wizard et page longue : toutes les sections sont sur une page, mais chacune est pliée par défaut. Le client ouvre ce qu'il veut remplir, ferme quand c'est fait. Vue d'ensemble + pas écrasé visuellement.

Votre note
★★ ★★★

✓ Avantages

  • Vue d'ensemble + ne pas tout afficher d'un coup
  • Le client choisit son rythme
  • Très bien sur desktop ET mobile
  • Cases « ✓ Section complétée » très satisfaisantes

✗ Inconvénients

  • UX moins évidente pour les clients âgés / peu tech
  • Pas de progression linéaire forcée
  • Plus de code à entretenir
  • Possible d'oublier une section pliée
